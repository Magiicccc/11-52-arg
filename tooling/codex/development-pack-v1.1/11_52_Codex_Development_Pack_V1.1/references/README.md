# 视觉参考安装

将 `11_52_UI_Reference_Pack_V1.0_全量冻结版.zip` 解压到：

`references/ui/11_52_UI_Reference_Pack_V1.0_全量版/`

1. `raw/`原图；
2. `annotated/`标注图；
3. `measurements.json`；
4. `implementation-contract.md`；
5. Word中的说明；
6. 临时网络搜索结果。
