# DEFINITION_OF_DONE.md

## 仓库级

- 前五册和UI Reference Pack校验通过。
- `pnpm qa`通过。
- 无未记录的剧情冲突、参考缺口和Schema错误。
- 所有新增内容ID可被引用且无孤儿资源。
- 所有正式内容通过叙事语义审计；无功能孤儿内容为0。

## 页面级

- 可进入、可交互、可退出、可刷新恢复。
- 使用DOM/CSS，不是静态整页截图。
- 关键行为发出规范事件。
- 目标视口视觉回归通过。
- 键盘、弹层、滚动和安全区行为合理。

## 场景级

- 前置门槛正确。
- 主证据和补救证据均可达。
- 响应来源H/A/P/C明确。
- 重复进入不重复副作用。
- 玩家在允许的非线性顺序下仍可完成。

## 垂直切片级

- 一次完整新存档可通关P00—A2-11。
- 中途任意检查点刷新后可以继续。
- 断网或关键媒体失败时仍可继续主线。
- 两部手机同步修正不丢事务。
- 所有可见App通过打开/交互/返回烟雾测试。
- 没有Lorem ipsum、未标记TODO、随机生成正式闲聊或通用假界面。
- 普通内容具有人物、关系或世界价值，但不被强迫变成谜题。
