# DAILY_CONTENT_AUDIT.md

## 构建门禁

- [ ] 每个正式ContentItem均有NarrativeMetadata。
- [ ] 孤儿内容数量为0。
- [ ] 主要功能不是“填充”“真实感”或“气氛”这种不可验证描述。
- [ ] 沈川、玩家、陈屿、周岚、阿序均有案外生活线。
- [ ] 首个垂直切片约65%以上可见内容属于普通生活。
- [ ] `clueRole: direct`在早期可见内容中保持少数。
- [ ] 同一生活事实跨App时内容互补，不复制同一句话。
- [ ] 重要修正对象在修正前已有firstReadValue。
- [ ] 不存在运行时随机生成的正式闲聊、评论、订单或浏览记录。
- [ ] 日期、金额、地点、物件、称呼和账号归属一致。

## 人工审计问题

1. 删除这条内容会让人物或世界变薄吗？
2. 它像这个人物在这个App里真的会做的事吗？
3. 它是否过度围绕主线？
4. 它第一遍就有正常阅读价值吗？
5. 它后期被修改时，玩家能理解失去了什么吗？
