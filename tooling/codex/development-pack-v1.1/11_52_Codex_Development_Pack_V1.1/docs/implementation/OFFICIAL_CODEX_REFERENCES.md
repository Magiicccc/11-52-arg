# OpenAI官方Codex资料基线（2026-07-16核验）

- Custom instructions with AGENTS.md：Codex在开始工作前读取AGENTS.md。
- Prompting Codex：任务应说明目标、相关文件/复现步骤、约束和验证方式。
- Frontend / browser game use cases：使用截图作为视觉输入，并在真实浏览器中通过自动化测试迭代。
- Agent approvals & security：沙箱决定可访问范围，审批策略决定越界操作何时暂停。
- Codex CLI / IDE：支持代码编辑、命令执行、图片输入和仓库上下文。

这些资料只用于制定Codex工作方式，不覆盖本项目的冻结剧情、系统与视觉权威。
