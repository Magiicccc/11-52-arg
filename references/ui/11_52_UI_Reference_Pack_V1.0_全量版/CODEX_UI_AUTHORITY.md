# CODEX_UI_AUTHORITY

## 视觉权威

1. 本包 `apps/*/raw/` 是项目视觉第一权威。
2. `state-matrix.md` 中的 `derived_real` 表示：页面没有一张一模一样的公开截图，但其全部组件和布局语法必须从同一App直接真实截图重组；不是自由设计。
3. `system_inherited` 表示：键盘、弹窗、通知、权限、分享面板等由 `iOS系统` 真实参考继承。
4. Codex不得把网络搜索结果静默覆盖本包。发现App版本变化时，只记录到实现报告；当前私人测试版本仍按本包冻结。

## 实施门禁

- Gate 1：读取目标App所有参考与合同。
- Gate 2：使用中性内容完成DOM/CSS复刻。
- Gate 3：Playwright在402×874和440×956截图。
- Gate 4：修正字体、间距、密度、滚动、弹层与点击热区。
- Gate 5：注入Content Bible内容。
- Gate 6：加入交互、事件和R0—R5版本。
- Gate 7：全桌面图标遍历、刷新恢复与视觉回归。

## 禁止

- 禁止凭模型记忆设计现实App。
- 禁止跨App借用组件来填补视觉缺口。
- 禁止Emoji代替App图标。
- 禁止整张截图作为页面背景。
- 禁止用剧情异常掩盖基础UI不真实。
