# Codex实现合同

## 角色
支付、账单、订单和双人消费证据。

## 强制顺序

1. 读取本目录 `manifest.json`、`source-log.md`、`state-matrix.md` 和 `raw/`。
2. 先使用中性占位内容完成DOM/CSS复刻。
3. 在402×874和440×956视口运行Playwright截图。
4. 对照真实参考修正字体、间距、密度、导航、滚动、弹层和点击热区。
5. 中性复刻通过后，才注入Content Bible中的沈川、潘博文、玩家和普通生活内容。
6. 最后加入R0—R5现实修正版本并重新做视觉回归。

## 交互合同
- 账单、金额、商户、支付时间和详情页可点击；不接真实支付。

## 内容注入边界
- 注入双人咖啡、酒店、交通和设备购买记录。

## 禁止项
- 禁止凭记忆设计“像某App”的通用页面。
- 禁止把整张参考截图作为不可交互背景。
- 禁止为了剧情改变现实App的导航结构和组件语法。
- 禁止使用Emoji或随手绘制图形替代官方App图标。
- 禁止把同一异常视觉滤镜铺到所有App。
