# 中文互联网头像真实性审计

日期：2026-07-19

分支：`fix/github-pages-ui-realism`
基线提交：`6cb5f28`

## 结论

原有 128 张头像来自 DiceBear 的 `lorelei`、`adventurer` 与 `personas` 三套程序化插画。虽然文件唯一、加载稳定，但人物比例、背景、线条与表情具有明显的同源生成器特征，无法复现中文互联网中混合、随意且跨媒介的头像生态，因此不得作为最终玩家可见资产。

冻结微信、小红书、知乎和贴吧参考显示，真实页面中的头像不是统一风格：

- 微信：家庭或朋友合照、花草、宠物、随手自拍、旅行风景、生活物件、群聊场景与服务账号并存。
- 小红书：生活方式自拍、宠物、摄影作品、穿搭局部、插画和少量品牌或机构账号并存。
- 知乎：普通真人照、插画、动物、极简图形与话题型账号并存。
- 贴吧：二次元、游戏或兴趣圈插画、梗图、宠物、真人与图形符号占比更高。

## 生产规则

1. 不再按“平台连续槽位”随机分配头像；使用稳定实体 ID 绑定同一人物。
2. 同一人物跨会话列表、聊天页、详情页和其他App时必须保持同一头像。
3. 核心剧情身份不生成会提前泄露身份的正脸，使用已授权的非脸部生活照片。
4. 每张位图独立生成和审核，禁止再次使用大宫格请求后机械认定全部合格。
5. 头像类型必须混合，禁止统一灯光、统一背景、统一脸型或统一画风。
6. 服务号、群聊和个人账号必须采用不同的视觉来源。
7. 生成图不得包含可读地址、真实地点绑定、品牌Logo、水印、剧情线索或异常。
8. 玩家界面不得继续显示单字头像或回退到 DiceBear 卡通头像。
