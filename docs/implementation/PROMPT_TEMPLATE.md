## 禁止修改

列出冻结剧情、数据合同、其他App或不在范围内的系统。

## 实施要求

1. 先检查现状和已有测试。
2. 先完成中性结构或引擎合同，再注入剧情。
3. 所有关键行为生成规范事件。
4. 不得写死一次性页面状态。
5. 缺口写入明确报告，不自行创作。
6. 注入任何普通内容前，验证其NarrativeMetadata；不得以随机文本填满列表。
7. 有意义不等于线索化，默认允许并优先保留`clueRole: none`。
